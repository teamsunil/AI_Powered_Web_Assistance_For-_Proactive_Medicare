How the assistant works

The assistant only answers from Proactive Medicare's own content. In this proof of concept that content is a structured knowledge base inside the page. In production it is pulled from the website's CMS or backend, so when the website changes, the assistant's answers change with it.

If the answer isn't in that content, the assistant says so and offers to connect the visitor with the team. It never makes up services, prices or policies, and it never gives medical advice.

    1. Website / CMS

      Service pages, areas covered, contact details and FAQs, as edited by the Proactive Medicare team.

    2. Content / API

      Pages are pulled from the CMS on a schedule or when they're published, then split into short passages.

    3. AI knowledge layer (RAG)

      Passages are indexed in a vector store. Each question retrieves the most relevant passages.

    4. AI assistant

      A language model writes the reply using only the retrieved passages, with safety rules for medical and emergency questions.

    5. Website visitor

      Gets an answer, a link to the right page, or a quick way to send an enquiry to the team.
